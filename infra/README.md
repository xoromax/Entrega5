# Infraestructura

Este módulo contiene la infraestructura desplegada mediante Terraform para soportar el procesamiento de datos en tiempo real.

## Componentes

- Amazon Kinesis Data Streams
- Amazon Managed Service for Apache Flink
- AWS Glue Catalog
- Amazon S3 Lakehouse
- IAM Roles y Policies
- Athena

## Despliegue

terraform init
terraform validate
terraform plan
terraform apply
